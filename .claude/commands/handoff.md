지금까지의 작업을 다른 PC에서 새 세션으로 이어갈 수 있도록
프로젝트 루트의 HANDOFF.md에 인수인계 노트를 작성해줘.
(기존 파일이 있으면 덮어써)

포함할 내용:
1. 작업 목표: 이번 작업이 무엇을 하려는 것인지 한두 문장
2. 완료한 것: 변경한 파일과 핵심 변경 내용
3. 주요 결정과 이유: 채택한 방식, 기각한 대안과 그 이유
4. 현재 상태: 동작하는 것 / 깨져 있거나 미완성인 것
5. 다음 할 일: 우선순위 순서로 구체적인 작업 목록
6. 주의사항: 헤맸던 문제, 환경 설정, 실행 방법, 알아낸 함정

대화를 요약하지 말고, 이 대화를 전혀 모르는 사람이
이 파일만 읽고 바로 이어서 작업할 수 있는 수준으로 써줘.
